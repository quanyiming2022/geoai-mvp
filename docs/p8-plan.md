# P8 Mock GeoExtract end to end
Bind ready raster + Visual Prompt + AOI to an immutable job request with composite project FKs. Worker reads actual support artifacts and bounded AOI crop, calls ComputeProvider/MockAdapter, intersects mock probabilities with AOI mask, polygonizes in native CRS and transforms to WGS84. Atomically fence result persistence with job completion. Keep original geometries immutable; accept/reject creates DB audit records. Map updates by polling and displays review states; export accepted GeoJSON includes model/source/job/time. Verify upload->COG->prompt/AOI->job->results->review->export, RLS and cancellation locally before commit/push. No real model/GPU or cloud execution.
