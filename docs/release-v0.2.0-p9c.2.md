# v0.2.0-p9c.2 — P9C 加固版本

基于 [v0.2.0-p9c.1](release-v0.2.0-p9c.1.md)，应用功能与该版本相同：工作流绘制返回、窗口清理、助手续接、影像共享资产与结果管理均已本地回归通过。

本维护修正仅改进长时间浏览器 fixture 的清理：在删除文件前锁定资产并检查外部项目链接（包括已移除链接）、Job 和 Prompt 引用。有外部引用时保留资产/文件；无活动引用的保留资产从库中软隐藏。临时账号、项目及专属对象仍正常清理。

发现问题时，数据库 FK 阻止了资产记录删除；先前清理已删去文件，因此从已校验的原始 TIFF 恢复源文件，并通过原有转换代码重建 COG/缩略图，下载校验与本地生成文件一致。没有外部 Job/Prompt 使用此测试资产，真实项目历史链接未删除。

实际验证：临时项目/账号已删除；被历史引用的资产仍在，3 个存储对象保留。日志：`artifacts/release-retained-asset-recovery.log`、`artifacts/release-safe-cleanup.log`。此前全套产品功能验收见 `.1` 文档；本补丁不修改 API、数据库 schema 或模型逻辑。

阶段仍是 **P9C 加固**。P9B 工程集成通过，但模型能力未通过；P10/P11 未开始。
